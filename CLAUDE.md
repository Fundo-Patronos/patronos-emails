## Project Overview

Email service for Fundo Patrimonial Patronos (Unicamp's endowment fund) using React.email for templates and Resend for delivery. All email content is in Portuguese (PT-BR).

## Commands

```bash
# Development - preview templates locally at localhost:3000
npm run dev

# Export templates to static HTML (required before sending)
npm run export  # or: npx email export

# Send emails - use campaign-specific scripts in src/utils/
node src/utils/sendJantar8.js          # Example: send specific campaign
node src/utils/sendLembrete1Pending.js # Resume interrupted batch from pending JSON
```

## Architecture

### Directory Structure
- `emails/` - Email templates (JSX) at project root, not in src/
- `src/components/` - Reusable email components (Button, ButtonGroup, Hero, FeatureList, FeatureGrid, NumberedList, ImageGrid)
- `src/config/brand.js` - Brand colors, typography, links, organization info
- `src/utils/` - Campaign-specific sending scripts (one script per campaign/batch)
- `out/` - Exported HTML files (generated by `npm run export`)

### Component Import Pattern
Templates in `emails/` import from src:
```jsx
import { Hero, FeatureList, Button, brand } from '../src/components';
```

### Email-Specific Constraints
- **Inline styles only** - Tailwind classes work in preview but not in email clients
- **HTML tables for layout** - Flexbox not supported in email clients
- **PNG/JPG only** - SVG images blocked by most email clients
- **Absolute URLs required** - Images must be hosted externally (GitHub raw or patronos.org)
- **Max email size** - Gmail truncates HTML >102KB

### Resend API Usage
- Free tier has daily send limits; campaigns may need multi-day batching
- Use BCC for mass sends (privacy-compliant)
- `scheduledAt` parameter for scheduled sends (use `checkScheduledEmails.js` to verify)

### Campaign Script Pattern
New campaigns typically need a dedicated send script in `src/utils/`. Scripts read exported HTML from `out/`, configure recipients, and call the Resend API directly. When quota is hit mid-campaign, save remaining recipients to a `pending_*.json` file and create a corresponding `send*Pending.js` script to resume.

## Brand Configuration

Access via `brand` export from components:
- `brand.colors.gradient.css` - Primary gradient
- `brand.colors.text.primary` / `brand.colors.text.secondary` - Text colors (#111827, #6B7280)
- `brand.links.actions.donate` - Donation page (https://doa.re/patronos)
- `brand.organization.legalName` - "Associação Fundo Patrimonial Patronos"

### Typography Standard
All body paragraphs: 16px, color #6B7280, line-height 28px

## Workflow Notes

- Do NOT send test emails unless explicitly requested
- Do NOT commit after every change - wait for user instruction
- Run `npx email export` after template changes before sending
- For mass campaigns, pending recipients are saved to JSON files when quota is hit
